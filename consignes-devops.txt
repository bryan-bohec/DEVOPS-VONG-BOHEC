Projet DevOps
Travail en binôme.
Sujet de projet : libre.
Langage de programmation : libre.
But
Développer une application en respectant les règles du DevOps :
- Dépôt Git
- Pipeline CI
- Architecture logicielle en couches :
o Data
o Services
o Controller (web)
- Au moins deux services back (intégrés avec Docker)
- Tests de toutes le couches avec framework de :
o Tests unitaire
o Mocks web
- Bonne couverture de code
- Qualité logicielle élevée
Pas besoin de faire de la Continuous Delivery (hors programme).
Option (noté en bonus)
- Front Web
- Base de données
